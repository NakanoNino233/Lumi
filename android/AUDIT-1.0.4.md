# 1.0.4 检查与优化记录

检查日期：2026-11-17。基于 1.0.3 的本机 Android 工程。

## 已修复的问题

| 问题 | 改动 |
| --- | --- |
| 回复生成期间往上看历史，会被不断拉回底部；长回复可能只露出顶部 | 使用反向消息列表和用户滚动状态，只在跟随最新消息时滚动，增加“回到最新消息”按钮 |
| 打开记忆再返回，聊天文字草稿丢失；切换主页面丢失搜索词与位置 | 按页面保存状态，保留会话文字草稿、四个主页面的搜索词和滚动位置 |
| 点击重新生成先删除旧回复，缺少密钥或网络报错后原文无法找回 | 旧回复保留到新的完整回复成功返回；重试上下文排除待替换回复 |
| 打开好友编辑后，期间产生的好感、置顶与封面更新会被旧表单覆盖 | 保存时合并实时字段，编辑器只更新好友资料；修改名字同步私聊标题 |
| AI 动态、日记或记忆生成期间删除好友，后台结果可能写入失效的好友引用 | 当前操作完成后才允许删除好友；删除成功后才退出资料页 |
| 恢复备份与普通写入同时进行，界面与磁盘可能出现不一致 | 恢复期间阻止新编辑，主线程分配写入版本，等待旧写入并保存回滚副本，成功后重置页面状态 |
| 50–80 MB 的合法展开数据无法重新导入 | 单条 ZIP 数据使用剩余的 80 MB 展开限额；压缩包大小上限仍为 50 MB |
| API 配置另存后再点原配置，可能继续显示新配置的表单 | 点击已保存配置时明确重新载入对应表单与密钥，并隐藏密钥 |
| 没有好友时首页“开始对话”没有反应；备份页小屏/横屏内容不能滚动 | 无好友时进入创建页；备份页支持滚动 |

## 界面与操作优化

- 页面切换使用约 180–220 ms 的淡入与短距离移动，返回方向相反。
- 聊天工具栏、附件栏及后台操作提示平滑展开和收起。
- 好友搜索支持名字和说话风格，置顶与列表变化有位置动画。
- 聊天和朋友圈图片支持全屏预览、双指缩放、双击放大或还原。
- 图片在后台解码，以 20 MB 内存缓存复用预览，并限制解码尺寸，减少列表反复解码。
- 优化聊天首页索引，避免逐个会话重复遍历全部消息。
- 朋友圈底部选中态使用与页面一致的蓝灰色；长好友名截断；停止生成按钮补充无障碍名称。
- 新建好友的表单标识在 Activity 重建时保持，记忆输入与群聊名称、成员选择支持保存状态。

## 验证范围

具体编译、单元测试、设备测试、Release 安装和用户资料升级结果见 `VALIDATION.md` 的 1.0.4 节及发布目录 `test-reports`。

设备测试使用独立 LumiTest 模拟器和本机模拟服务，不使用用户聊天数据或真实 API 额度。
这次检查覆盖主要本机流程与明确复现的问题；真实模型服务、系统语音引擎和不同品牌真机仍需在相应环境验证。
