# Lumi 静态内容目录

Lumi 原生实现了内容市场，没有复制 dsh-market 代码，也不加载 Harness / npm 插件。

## 来源

默认源为 App 随附的离线示例目录 `Lumi-Market-Index.json`，含一张角色卡、一项技能、一个原创表情包和两套主题。示例内容为 CC0-1.0。App 不依赖在线官方内容服务器或镜像。

设置 → 内容市场 → 右上角“目录源”可以填写自己的 HTTPS `index.json` 和备用镜像。主目录失败后尝试镜像，两个地址均失败时读取该主源上次验证通过的缓存。拉动列表或“重试”重新加载；不同主源的缓存互不混用。切换源保留已安装内容，更新提示仅针对当前选定来源。

`index.schema.json` 描述远端目录。`index.example.json` 是供替换地址的示例，**example.invalid 并非可用服务**。`index.bundled.json` 是本次随 App 交付的真实离线清单（`bundle:` 为内置内容专用，远端不能使用）。没有公开托管地址，因此未提供可直接使用的默认线上镜像。

目录与资源可以放在 GitHub Pages 等直接提供静态文件的 HTTPS 服务。支持最多 5 次 HTTPS 重定向，跳转时重新构造匿名 GET 请求，拒绝降级到 HTTP 或带账号密码的地址；可用于 GitHub Release 的资源跳转。最终资源仍须通过精确大小和 SHA-256 校验。源地址不能含凭据、查询参数或 fragment。下载不携带 API Key、聊天、登录 cookie 或系统保存的凭据。

## 字段与限制

每项包含 `id/type/name/author/summary/version/downloadURL/sha256/size/license`，可选 `previewURL`。版本为严格的三段非负数字（每段最多 9 位，不接受前导零、预发布或 build 后缀），按数值比较。相同版本更换校验值不会自动覆盖安装。

- 索引上限 1 MB、500 项；ID 唯一，最多 80 个 ASCII 字母、数字或 `._-`。
- 角色：JSON，最多 12 MB；使用现有 CharacterCard v1 字段。可选 `tools` 是受支持工具名数组，仅展示、不授权。拒绝其他字段；图片通过原有缩放与尺寸校验。
- 技能：SKILL.md 或 ZIP，最多 5 MB。复用现有技能解析和 ZIP 限制（最多 30 项技能、每项 128 KB、200 条 ZIP 记录、解压总量 4 MB）。拒绝链接、路径穿越、重复路径、未知权限和脚本。
- 表情：ZIP，市场下载上限 30 MB；解压沿用图库 300 MB / 1000 张 / 单图 10 MB、路径、链接、CRC、图片与可选逐图 SHA-256 验证。
- 主题：JSON，最多 16 KB。仅允许 `schemaVersion/accent/bubble/background/font/bubbleStyle`；颜色为六位 RGB，背景可为空。字体仅 `system/rounded/serif/monospaced`；气泡仅 `rounded/soft/square`。不接受字体下载、脚本、CSS 或任意字段。
- 可选预览图按 HTTPS 下载，上限 2 MB，并检查图片尺寸/格式；失败只显示占位，不影响安装。
- 下载时逐字节限制长度，收到内容再比较目录声明的精确大小和 SHA-256。校验只能证明文件与当前目录一致，不证明目录作者身份；选择自己信任的目录源。

## 安装与维护

下载与解析只生成预览，确认前不改数据库。角色、技能、表情的数据库变更与市场收据一起提交；表情新文件先准备，失败时清理，新事务成功后才移除旧文件。每项保存当前资源和上一版资源，支持离线回滚一次。回滚后可再次更新，不能继续回滚更早版本。

角色更新沿用好友 ID，保留聊天、记忆、关系进度、置顶、通知等，仅替换卡片设定；更新会覆盖手动编辑过的人设。卸载角色卡只解除市场管理，不删除好友。重新安装遇到同名好友会拒绝，以免覆盖本地好友；可先改名，或继续使用原好友。

技能同名更新保留技能 ID 和启停状态。新增技能按普通导入启用，但所需工具仍由现有聊天授权处理。卸载删除该包技能。表情包更新替换图库包，保持启停状态；已发送消息持有图片快照，不受卸载影响。

主题安装即应用并记录原有外观。回滚应用上一版。卸载当前主题时，仅在当前外观仍等于该主题时恢复安装前外观；用户手动改过的配色或样式不会被覆盖。主题只改变普通聊天文字字体和气泡、强调色及背景，不更改系统界面字体。

主题的收据先存入数据库，再写入偏好设置；强制终止发生在二者之间时，收据可能已存在但主题未应用，可卸载后重装。表情新目录在进程被系统强制结束时可能残留未引用文件，普通错误路径已清理；没有宣称跨文件与数据库具备系统级原子事务。

## 提示注入边界

外部角色资料编码为 JSON，转义尖括号并置于 `<persona_data>` 中；安全规则保持独立、完整且在最前。技能也以数据区块加载，不存在下载代码执行入口或自行扩大工具白名单的入口。测试验证结构、转义、安全前缀和无自动授权，不能证明任意远端模型永远不会服从恶意文字。仍需对真实模型进行对抗性人工验证，本次没有发送付费 API 请求。
